## 项目简介
本项目将 `ose.py` WPS测试脚本封装为Android APK应用。

原生Android环境直接运行该脚本需要部署Termux、配置运行环境并执行大量命令。本APK内置完整运行环境，安装后可直接执行相关测试流程。

工作原理说明：
本工具针对路由器WPS协议交互流程，结合pixiewps实现WPS‑PIN离线计算，通过获取PIN推导WPA密钥。
**本项目不属于WiFi密码分享类工具，亦不基于字典实施暴力密码破解。**

若目标路由器已关闭WPS功能，则本工具无法执行测试逻辑。目前多数新型路由器出厂默认禁用WPS，实际扫描过程中可能不存在可测试目标。

## 功能说明
### 主页：扫描与测试
点击「开始」后程序自动执行以下流程：
1. 识别系统无线网卡设备（例：`wlan0`）并初始化；
2. 扫描周边无线网络，筛选出开启WPS功能的接入点；
3. 按照信号强度由高至低排序，依次执行测试流程；
4. 已获取的PIN及密钥将保存至本地密码本文件 `wifipassword.txt`。

> 注意：程序仅执行密码存储操作，**不会自动连接无线网络**，网络连接需要用户手动完成，避免非预期接入未知网络。
界面下方终端日志区域实时输出运行信息，包含目标接入点、信号强度、PIN运行状态等调试内容。

### 通知栏快捷磁贴
可在通知栏添加名为「**扫描周围WiFi**」的系统快捷磁贴，触发后在后台执行完整扫描任务，无需打开应用。任务运行期间磁贴状态高亮，再次点击终止任务。

> 受Android系统权限限制，应用无法自动添加系统磁贴，需要用户手动配置：下拉通知栏 → 展开完整面板 → 点击编辑，将磁贴组件添加至快捷面板。

### 密码本管理
第二个Tab页面为密码本，读取并展示 `wifipassword.txt` 的存储内容。
右上角功能按钮：
- 磁盘图标（左侧）：将密码本导出至本地存储，调用系统保存界面，支持用户自定义存储位置完成备份。
- 垃圾桶图标（右侧）：清空密码本全部记录，操作将弹出确认弹窗，数据删除后不可恢复。

多条测试结果独立存储，不会发生数据覆盖。
